I build and repair production software on Linux and Windows: CMS sites, custom apps, servers, and databases. When the same problem keeps biting me at home, I sometimes turn it into an open tool.

[Work](/work) has case studies. [Contact](/contact) is the form (no public email on this site).

## Background

I started with an AAS in Networking in 2004. Help desk and Active Directory paid the bills for a bit; I wanted to build systems, not only clear tickets.

I’ve been building websites professionally since **2006**. The next decade was mostly self-taught PHP, Python, SQL, and C# on real projects. In 2013 I went back for a BS in CIS focused on web development (the code side, not design). I finished in **2015** with Objective-C, modern JavaScript, and some formal project management, while working full-time for the same company I’ve been with since **2010**.

The catalog since then is messy in a good way: WordPress, Drupal, Magento, Episerver, Concrete CMS; MEAN, Rails, PHP and C# frameworks; Linux and Windows; NGINX and Apache; MySQL, MSSQL, PostgreSQL, MongoDB. A few mobile apps I’d rather forget. Pattern that stuck: keep live systems honest, then modernize when the business can afford the change.

## Work I take

**Legacy repair and modernization.** Fragile C#/.NET or PHP estates. Stabilize first, then move toward headless or Next.js / Astro when that earns its keep.

**Servers and databases.** OS hygiene, patching, cloud moves, MySQL/MSSQL and friends so environments stay available.

**Second opinions.** Debt, query bottlenecks, and “what breaks first if we wait another year.”

**SEO and AEO.** I’ve worked alongside SEO firms on CMS and custom sites, and I’m Google Analytics certified. On builds I care about crawlable markup, sane information architecture, structured data when it helps, and making pages readable for search and answer engines (AEO) without stuffing keywords. This site’s `llms.txt`, schema, and docs hub are part of that habit.

**Products when the product is the point.** Monitoring, prompt tooling, IoT ingest. I’d rather ship the thing than another slide deck.

Freelance work includes server setup and Concrete CMS for [stjohnnorfolk.org](https://stjohnnorfolk.org/) (still live), with PCI/DSS help when they need it. Older ecommerce and cinema pieces (gift certificates, RTS / CinemaSource, Affirm for Community Store) are linked from [Work](/work).

## How jobs usually go

Inherited stacks almost never need a full rewrite on day one. First wins are uptime, backups, query performance, and patching. Fashionable front ends come later.

When we do modernize, I try to keep years of content and business logic intact and put a maintainable edge in front. Docs and operator notes matter; Prompt Studio and ThermalTrace both reflect that habit.

## Open products

**[LLM Prompt Studio](/llm-prompt-studio)** is an MIT-licensed Next.js studio for ComfyUI and cloud stills/clips: prompt tools, Play campaigns, workflow takeover, gallery review, desktop and Docker. Docs on this domain; operator reference on GitHub Pages.

**[ThermalTrace](/work/thermaltrace)** is open monitoring at [thermaltrace.dev](https://thermaltrace.dev/) for garages, workshops, and similar spaces. ESP32/Pico (and other) ingest, freeze and flood alerts, history, household sharing, companion apps. Built around hardware people already own.

Both are running software, not mockups.

I don’t run a pure SEO agency. I implement and advise from the engineering side: structure, performance, analytics, schema, and content that search and answer engines can use. Happy to work with your SEO people or pick up the technical pieces.
