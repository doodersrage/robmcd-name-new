**Welcome to my corner of the internet, where I share my work and hobbies.**

I've been building websites professionally since 2006. My tech career actually started with an AAS in Networking back in 2004, but after a stint handling help desk tickets and Active Directory, I knew I wanted to build things rather than just maintain them.

I spent the next decade teaching myself everything from PHP and Python to SQL and C#. In 2013, I went back to college for a BS in CIS with a strict focus on Web Development (the code side, not the design side). That program added Objective-C, modern JS, and formal project management to my arsenal by the time I wrapped up in 2015—all while working full-time for the same company I've been with since 2010.

Since then, I've deployed a massive catalog of sites. I've worked with almost every major CMS (WordPress, Drupal, Magento, Episerver) and built custom applications using the MEAN stack, Ruby on Rails, and standard PHP/C# frameworks. (I even built a few forgettable mobile apps along the way, but we don't talk about those). When a project demands it, I also step into the DevOps role to configure Linux/Windows servers, NGINX/Apache proxies, and robust database backends like PostgreSQL and MongoDB. It's been an incredibly fun—and occasionally frustrating—ride.

Freelance client work includes server setup and Concrete CMS implementation for [stjohnnorfolk.org](https://stjohnnorfolk.org/), with ongoing PCI/DSS compliance support as needed.

Open products: [LLM Prompt Studio](/llm-prompt-studio) docs on this site, and [ThermalTrace](/work/thermaltrace) (live at [thermaltrace.dev](https://thermaltrace.dev/)).

## Common questions

### What kind of work do you take on?

Legacy repair and stack modernization, Linux/Windows server maintenance, MySQL/MSSQL administration, and technical audits — plus product work like Prompt Studio and ThermalTrace when those patterns apply.

### What is LLM Prompt Studio?

An MIT-licensed Next.js studio for ComfyUI and cloud stills/clips: prompt tools, Play campaigns, workflow takeover, and desktop/Docker installs. Docs live at [/llm-prompt-studio](/llm-prompt-studio).

### What is ThermalTrace?

Open-source garage and workshop monitoring for freeze and flood risk — ESP32/Pico ingest, household alerts, and companion apps. Write-up on this site at [/work/thermaltrace](/work/thermaltrace); product at [thermaltrace.dev](https://thermaltrace.dev/).
