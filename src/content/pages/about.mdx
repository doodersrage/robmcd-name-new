## Background

I started with an AAS in Networking in 2004. Help desk and Active Directory paid the bills for a bit; I wanted to build systems, not only clear tickets.

I’ve been building websites professionally since **2006**. The next decade was mostly self-taught PHP, Python, SQL, and C# on real projects. In 2013 I went back for a BS in CIS focused on web development (the code side, not design). I finished in **2015** with Objective-C, modern JavaScript, and some formal project management, while working full-time for the same company I’ve been with since **2010**.

The catalog since then is messy in a good way: WordPress, Drupal, Magento, Episerver, Concrete CMS; MEAN, Rails, PHP and C# frameworks; Linux and Windows; NGINX and Apache; MySQL, MSSQL, PostgreSQL, MongoDB. A few mobile apps I’d rather forget. Pattern that stuck: keep live systems honest, then modernize when the business can afford the change.

## How jobs usually go

Inherited stacks almost never need a full rewrite on day one. First wins are uptime, backups, query performance, and patching. Fashionable front ends come later.

When we do modernize, I try to keep years of content and business logic intact and put a maintainable edge in front. Docs and operator notes matter; Castcut and ProbeHarbor both reflect that habit.

## Open products

**[Castcut](/castcut/)** is an MIT-licensed Next.js app for local AI character filmmaking with ComfyUI: Cast → Outfit → Day → Scene → Cut film. Castcut {VERSIONS.castcut} imports a screenplay, renders Scenes one take at a time, shows a storyboard and animatic, and has talking clips with sound and room tone, Cast voices (auditioned or your own recording), narration, an original score for each cut, Cast homes that keep marks, props, and a wardrobe, widescreen cuts with close-ups, review links, finishing tools (lip-sync, copy moves from a video, relight), a Film Director page, and export to an editor's timeline, alongside identity lock, the pose editor, optional [Castcut nodes](/castcut/integration/castcut-nodes/), Heal & ready, Mobile Studio, desktop and Docker. Docs on this domain; operator reference on GitHub Pages; a live instance runs in my [homelab](/homelab/).

**[Prompt Studio](/work/prompt-studio/)** is where Castcut started. The classic prompt, image, video, and audio tools now ship as their own app, built on the shared [prompt-studio-core](https://www.npmjs.com/package/prompt-studio-core) package, so Castcut can stay focused on films.

**[ProbeHarbor](/work/probeharbor/)** (formerly ThermalTrace) is open monitoring at [probeharbor.dev](https://probeharbor.dev/) for garages, workshops, and similar spaces. ESP32/Pico (and other) ingest with a browser flasher for ESP32 boards, freeze, heat, and flood alerts, a public [pipe-freeze forecast](/work/probeharbor/forecast/) with free freeze-night emails, history, household sharing, companion apps (Android, iOS, Desktop, Bay Buddy), [integrations](/work/probeharbor/integrations/) (Matter, Home Assistant, Node-RED, Influx), and a claim puck for field installs. Built around hardware people already own.

**[Shelf](/work/shelf/)** is a self-hosted personal library on .NET 10 and Blazor: the catalog, reading log, quotes, and loans for a household, with a full-screen page-turning e-book reader, an audiobook player, Kobo and KOReader sync, imports from Calibre, Goodreads, and Audiobookshelf, books found and fetched the way Sonarr fetches shows, and shelves read from a photo of the spines. One Docker container, AGPL-licensed, with [documentation on GitHub Pages](https://doodersrage.github.io/shelf/).

All of them are running software, not mockups.

## Common questions

### What kind of work do you take on?

Legacy repair and modernization, Linux/Windows server maintenance, MySQL/MSSQL administration, technical audits, SEO/AEO-minded site work (I’m Google Analytics certified and have worked with SEO companies), and product work like Castcut or ProbeHarbor when that fits.

### Do you do SEO as a standalone service?

I don’t run a pure SEO agency. I implement and advise from the engineering side: structure, performance, analytics, schema, and content that search and answer engines can use. Happy to work with your SEO people or pick up the technical pieces.

### Do you only do greenfield builds?

No. Most useful work starts with what’s already running. Greenfield only when the old stack really can’t carry another year.

### What is Castcut?

Local character films with ComfyUI — Cast → Outfit → Day → Scene → Cut film, now from a screenplay to a finished cut, with talking clips, a score, re-cuts in any shape, and export to an editor (Castcut {VERSIONS.castcut}). It began as Prompt Studio; the classic tools now ship separately as [Prompt Studio](/work/prompt-studio/). Docs: [/castcut](/castcut/).

### What is ProbeHarbor?

Garage and workshop freeze, heat, and flood monitoring with ESP32/Pico ingest, alerts, a pipe-freeze forecast, companion apps, and Matter/HA/Node-RED hooks. It was called ThermalTrace until October 2026. Write-up: [/work/probeharbor](/work/probeharbor/). Product: [probeharbor.dev](https://probeharbor.dev/).

### What is Shelf?

A self-hosted library for a household's books, e-books, and audiobooks, with lending between readers. Write-up: [/work/shelf](/work/shelf/). Docs: [doodersrage.github.io/shelf](https://doodersrage.github.io/shelf/). Source: [GitHub](https://github.com/doodersrage/shelf).
